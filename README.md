# Container Network Interface (cni)
CNI is a CNCF incubating specification for configuring network interfaces in Linux containers. It provides a pluggable interface between container runtimes and network plugins, used by Kubernetes and other orchestrators.

## APIs

### CNI Specification
The CNI specification defines the interface between container runtimes and network plugins, covering ADD, DEL, CHECK, and VERSION operations for managing container network attachments.
